# AutoPost AI - 소상공인 올인원 SNS 마케팅 시스템

주제 한 줄 또는 사진/영상만 올리면 인스타그램, 틱톡, 네이버 블로그, 페이스북, X(트위터) 등에 맞는
**'텍스트 원고 + 타임라인 기반 자막 영상'**을 한 번에 만들어주는 자동화 솔루션입니다.

## 🚀 주요 기능
- **AI 텍스트 원고 생성**: 플랫폼별 글자 수 제한, 톤앤매너에 맞게 최적화된 원고와 해시태그 생성 (Gemini 기반)
- **주제 → 이미지 자동 생성**: 주제 텍스트만 입력하면 AI가 이미지 생성 프롬프트를 만들고, 무료 이미지 생성 서비스(Pollinations.ai)로 실제 이미지를 만들어줍니다.
- **타임라인 에디터**: 업로드/생성된 이미지(기본 2초)·영상(기본 4초)을 순서대로 배치하고 BGM을 합성해 하나의 영상으로 렌더링합니다.
- **저비용 영상 스타일 분석**: 영상 전체를 분석하지 않고, 균등 간격의 프레임 몇 장만 캡처해 Gemini Vision으로 자막 위치/색상을 추천받습니다.
- **스타일 클론(데모)**: 참고하고 싶은 사이트 URL을 입력하면, 실제로 그 사이트에 접속하지 않고 준비된 스타일 프리셋 중 하나를 추천해줍니다.
- **SNS 자동/반자동 발행**: 인스타그램·페이스북(Meta Graph API), X(트위터, tweepy), 네이버 블로그(반자동 — 공식 글쓰기 API가 없어 클립보드 복사+새창), 틱톡(Content Posting API, 계정 연결 필요)
- **예약 발행 스케줄러**: 정해진 시간에 텍스트와 영상을 백그라운드에서 예약 전송 (APScheduler, 1분 간격)

## 💻 설치 및 실행 방법 (Windows)

본 프로그램은 파이썬(Python 3.10 이상)이 설치되어 있어야 합니다.

### 1. 환경 설정 (.env)
루트 폴더에 있는 `.env.example` 파일을 복사하여 `.env`로 이름을 변경하고 필요한 키를 입력하세요.

```env
# 필수: 원고 생성 + 이미지 생성 프롬프트 + 영상 스타일 분석에 사용
GEMINI_API_KEY=your-gemini-api-key-here
```

> 구글 AI Studio에서 발급받은 Gemini API 키를 넣으면 원고 생성/이미지 자동생성/영상 스타일 분석 기능이 모두 동작합니다. 이미지 실제 생성 자체는 무료 서비스(Pollinations.ai)를 쓰므로 별도 키가 필요 없습니다.

각 SNS 발행 기능을 쓰려면 아래 키도 필요합니다 (`.env.example`에 상세 설명 포함):
- **인스타그램/페이스북**: `META_APP_ID`, `META_APP_SECRET` (Meta 개발자 앱), 서버 실행 후 `/auth/meta/login`으로 최초 1회 로그인
- **네이버 블로그**: `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` (반자동 발행이라 발행 자체엔 로그인 불필요, 원고 페이지 이동만 지원)
- **X(트위터)**: `X_API_KEY`, `X_API_SECRET`, `X_ACCESS_TOKEN`, `X_ACCESS_TOKEN_SECRET`
- **틱톡**: `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET`, `/auth/tiktok/login`으로 최초 1회 로그인 (현재 TikTok 개발자 포털의 Redirect URI 검증 이슈로 신규 앱 등록이 막혀 있을 수 있음 — TikTok 측 이슈)

### 2. 영상 합성을 위한 필수 외부 패키지 설치
이 프로그램은 자막 합성을 위해 **FFmpeg**와 **ImageMagick**을 필수적으로 요구합니다.

*   **FFmpeg**: [ffmpeg.org](https://ffmpeg.org/download.html)에서 윈도우용 빌드를 다운로드 받아 압축을 풀고, `bin` 폴더 경로를 윈도우 **환경 변수 PATH**에 추가해 주세요.
*   **ImageMagick**: [imagemagick.org](https://imagemagick.org/script/download.php#windows)에서 설치 파일을 다운로드하여 설치합니다. **설치 시 주의사항:** 설치 체크박스 중 `"Install legacy utilities (e.g. convert)"` 항목을 **반드시 체크**해야 MoviePy가 정상적으로 텍스트를 렌더링할 수 있습니다.

### 3. 서버 실행 (원클릭)
폴더에 있는 `start.bat` 파일을 더블 클릭하여 실행합니다.
- 최초 실행 시 자동으로 가상환경(`venv`)을 만들고 필수 패키지를 설치합니다.
- 서버가 켜지면 크롬 브라우저에서 `http://localhost:5000` 으로 접속하세요.

## ⚠️ 알려진 제한 사항
- **BGM 프리셋**: `static/assets/bgm/`에 기본 제공 음원 파일이 아직 준비되지 않았습니다. 화면의 BGM 프리셋 버튼은 "준비중"으로 표시되며, 대신 사용자가 직접 mp3/wav/m4a 파일을 업로드해 BGM으로 쓸 수 있습니다.
- **워터마크 제거(Pro)**: 화면에는 표시되지만 실제 워터마크 삽입 로직은 아직 구현되어 있지 않습니다.
- **결제/구독**: 무료/유료 플랜 UI만 있고 실제 결제 연동(PG)은 되어 있지 않습니다.
- **스타일 클론**: 데모용 기능으로, 실제 대상 URL에 접속하지 않고 준비된 스타일 프리셋 중 하나를 추천하는 방식입니다.
