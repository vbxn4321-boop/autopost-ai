# AutoPost AI - 소상공인 올인원 SNS 마케팅 시스템

주제 한 줄 또는 사진 한 장만 업로드하면 인스타그램 릴스, 틱톡, 당근마켓, 블로그 등에 최적화된 **'텍스트 원고 + 캡컷 스타일 자막 영상'**을 한 번에 찍어내는 자동화 솔루션입니다.

## 🚀 주요 기능
- **AI 텍스트 원고 생성**: 각 플랫폼별 글자 수 제한, 어투(친근한, 전문적인 등), 톤앤매너에 맞게 최적화된 원고와 해시태그 생성 (Gemini 기반)
- **캡컷 스타일 영상 렌더링**: 사용자가 고른 폰트, 색상, 위치, 배경 박스 등을 기반으로 MoviePy가 텍스트를 영상에 합성
- **사진 → 릴스 변환**: 동영상이 아닌 단순 '사진'을 업로드해도 자동으로 5초짜리 영상으로 변환하여 발행 가능
- **예약 발행 스케줄러**: 정해진 시간에 텍스트와 영상을 백그라운드에서 예약 전송
- **수익화 모델 탑재**: 무료 플랜(1일 3회 제한) 및 업그레이드 유도 UI 내장

## 💻 설치 및 실행 방법 (Windows)

본 프로그램은 파이썬(Python 3.10 이상)이 설치되어 있어야 합니다.

### 1. 환경 설정 (.env)
루트 폴더에 있는 `.env.example` 파일을 복사하여 `.env`로 이름을 변경하고 필수 키를 입력하세요.
```env
# 필수: Google Gemini API Key (원고 생성용)
OPENAI_API_KEY=your_gemini_api_key_here
```
> **참고**: `OPENAI_API_KEY` 환경변수 이름을 사용하지만 실제로는 Gemini 모델(`gemini-1.5-flash`)을 호출하도록 호환 라이브러리를 사용합니다. 구글 AI Studio에서 발급받은 키를 넣으시면 됩니다.

### 2. 영상 합성을 위한 필수 외부 패키지 설치
이 프로그램은 자막 합성을 위해 **FFmpeg**와 **ImageMagick**을 필수적으로 요구합니다.

*   **FFmpeg**: [ffmpeg.org](https://ffmpeg.org/download.html)에서 윈도우용 빌드를 다운로드 받아 압축을 풀고, `bin` 폴더 경로를 윈도우 **환경 변수 PATH**에 추가해 주세요.
*   **ImageMagick**: [imagemagick.org](https://imagemagick.org/script/download.php#windows)에서 설치 파일을 다운로드하여 설치합니다. **설치 시 주의사항:** 설치 체크박스 중 `"Install legacy utilities (e.g. convert)"` 항목을 **반드시 체크**해야 MoviePy가 정상적으로 텍스트를 렌더링할 수 있습니다.

### 3. 서버 실행 (원클릭)
폴더에 있는 `start.bat` 파일을 더블 클릭하여 실행합니다.
- 최초 실행 시 자동으로 가상환경(`venv`)을 만들고 필수 패키지를 설치합니다.
- 서버가 켜지면 크롬 브라우저에서 `http://localhost:5000` 으로 접속하세요.
